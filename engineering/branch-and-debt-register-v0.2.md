## Debt controls

- Strict UI controls remain hidden until the backend reports all required
  capabilities and a verified filter generation. There is no optimistic fallback.
- Every privileged command is a versioned enum; arbitrary executable, path,
  registry, service or shell operations are forbidden.
- Policy/app/session collections have explicit limits before entering privileged
  code. Driver misses, blocks and lease-expiry paths do not allocate, block the
  calling thread, log payloads or call user mode synchronously. A successful TCP
  redirect necessarily allocates one fixed 112-byte nonpaged context whose
  lifetime is owned by WFP; TD-018 prevents treating that cost as fully bounded.
- TCP relay connections use fixed 16 KiB buffers per direction, a single pump
  per accepted connection, bounded idle time and explicit cancellation. The
  listener pool has a fixed worker ceiling and one queued connection per lane;
  production wiring must not replace these bounds with per-connection threads.
- Core UDP ingress uses one socket and one receive goroutine per strict generation,
  not one socket or goroutine per target group. Health and data frames are
  generation-bound and HMAC-authenticated. Data state is capped at 1,024
  associations and 256 in-flight payloads, with 90-second idle expiry and a
  64-packet replay window. Broker uses one connected exact-loopback socket,
  two fixed frame buffers, stable credential indexes and at most 1,024
  associations; the per-datagram path performs no heap allocation or atomic
  reference counting. Driver/Broker batches are separately capped at 256 KiB,
  64 records and 16 KiB per payload, and reject stale/mismatched lease identity,
  reserved bytes, noncanonical padding and unsafe endpoints. Direct I/O shares
  the already attested overlapped device handle without holding the serialized
  control lock. Broker flow state is independently capped at 1,024 entries with
  90-second expiry and captured/reply replay windows; group, endpoint and flags
  cannot drift after admission. Driver capture accepts one NBL/NET_BUFFER and at
  most 16 KiB per classification without allocating or waiting, and absorbs only
  after one captured record is delivered. TD-023 prevents treating that bounded
  first slice as performance-qualified while it completes one IOCTL per datagram.
  This surface is not counted as a complete UDP data plane and cannot set
  UDP/DNS/QUIC capability bits.
- M3 commits are split into design/contract, state machine, Broker, driver,
  packaging and verification units. A commit never mixes generated UI churn or
  unrelated M2 fixes.
- Real WFP, route, DNS, TUN, firewall, service and driver installation tests are
  prohibited on the development host and remain VM-only.
