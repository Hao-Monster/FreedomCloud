## 维护方式

1. 保留任务编号；新增发现另加编号，不把现有项目静默删除或改成已完成。
2. 每项关闭时填写修复提交、测试/实机证据和残余风险。只完成代码、单测或构建时，应保留对应未完成验收勾选项。
3. 区分源码确认、隔离复现和真实运行验收；观察性探针 PASS 不代表产品没有缺陷。
4. 生产代码、包、服务、代理/TUN 和系统恢复操作各按当前授权执行。记录 TODO 本身不代表这些操作已经执行。
